# Question Bank canonical repository

https://github.com/shicheng0810/question-bank is the sole maintained source repository. Cloudflare https://question-bank-78u.pages.dev is the sole production application. The gh-pages branch retains the reviewed legacy redirect and migration package for https://shicheng0810.github.io/question-bank/; it does not publish the main source tree.

Main contains the reviewed allowlisted source, locked dependencies, synthetic tests and public immutable banks. Its merge preserves both prior repository histories. No environment secrets, private banks, learner records, raw reports or Telegram conversations are included in the current source tree.

Report automation remains disabled until exact approver identity, main required checks, audited trusted SHA, protected report-production environment, destination credentials, exact OIDC trust and actual deployment baseline are verified. A PR merge is not publication success: compatible Cloudflare deployment and exact revision/hash/domain/deployment readback are required. Correction PRs target main. The main dispatch caller invokes a same-repository reusable publication job at a literal reviewed commit SHA; signed job_workflow_sha pins both its workflow and tooling checkout. Caller sha/workflow_sha advances with main data and is bound separately to each operation/run/attempt. Recovery reads the recorded result commit and never re-deploys. The report-production environment remains main-only. REPORT_TRUSTED_SOURCE_SHA is retained for the producer; publication derives its checkout SHA from the called job identity.

The old question-bank-source repository is retained for historical audit and receives no ongoing source updates. Credentials are never copied out of it; destination secrets require secure user configuration.
