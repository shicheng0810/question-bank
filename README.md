# Question Bank canonical repository

https://github.com/shicheng0810/question-bank is the sole maintained source repository. Cloudflare https://question-bank-78u.pages.dev is the sole production application. The gh-pages branch retains the reviewed legacy redirect and migration package for https://shicheng0810.github.io/question-bank/; it does not publish the main source tree.

Main contains the reviewed allowlisted source, locked dependencies, synthetic tests and public immutable banks. Its merge preserves both prior repository histories. No environment secrets, private banks, learner records, raw reports or Telegram conversations are included in the current source tree.

Report automation remains disabled until exact approver identity, main required checks, audited trusted SHA, protected report-production environment, destination credentials, exact OIDC trust and actual deployment baseline are verified. A PR merge is not publication success: compatible Cloudflare deployment and exact revision/hash/domain/deployment readback are required. Correction PRs target main; proposed checkout is data only, trusted tooling is pinned to a reviewed SHA.

The old question-bank-source repository is retained for historical audit and receives no ongoing source updates. Credentials are never copied out of it; destination secrets require secure user configuration.
