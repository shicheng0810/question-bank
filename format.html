What to give the AI给 AI 什么材料

Start with copied text. Use screenshots for figures. Saved pages and PDFs need a computer and an AI that takes uploads.先用复制的文字；有图的题用截图；保存的网页和 PDF 需要电脑，并且 AI 要支持上传文件。

On a phone? Copy the text or take screenshots. Saving a web page or a PDF is for a computer.用手机？复制文字，或者截图。保存网页和导出 PDF 要在电脑上做。
Copied text复制的文字
Recommended推荐Any AI任何 AI

How做法Open the quiz results or review page that shows the correct answers. Select the questions (⌘A or Ctrl+A takes the whole page), copy, and paste them after the === MATERIAL === line.打开显示正确答案的测验结果或回顾页面，选中题目（⌘A 或 Ctrl+A 选中整页），复制，粘贴到 === MATERIAL === 那一行后面。

On a phone手机上Long-press the text, drag the handles or choose Select all, then Copy.长按文字，拖动两端的手柄或选全选，再点拷贝。

Works with适用Every AI, free ChatGPT and Gemini included. If it says the message is too long, send half the quiz first.所有 AI，包括免费版 ChatGPT 和 Gemini。如果它说消息太长，先发前一半。

Screenshots or photos截图或照片
Any AI任何 AIBest for figures有图的题

How做法One screen at a time. Each one must show the question, all the choices, the marked correct answer and any figure. Attach the images to the same message as the prompt.一次一屏。每张都要拍到题干、全部选项、标出的正确答案，以及题里的图。和提示词放在同一条消息里发送。

Works with适用Any AI that accepts images, on a phone too. Use it for questions that have a figure, which copied text loses.任何支持图片的 AI，手机上也行。带图的题用它，因为复制文字会丢掉图。

Saved web page .mhtml保存的网页 .mhtml
Computer only仅限电脑Upload needed需要上传文件

How做法In Chrome or Edge on a computer, press ⌘S or Ctrl+S, choose Webpage, Single File, and save. Attach the .mhtml file to your message.在电脑上的 Chrome 或 Edge 里按 ⌘S 或 Ctrl+S，格式选 Webpage, Single File（网页，单个文件）并保存。把 .mhtml 文件作为附件发给 AI。

Not Safari别用 SafariFile → Save As → Web Archive makes a .webarchive, which is not the same thing and AIs usually cannot read it. Use Chrome or Edge.Safari 的 文件 → 保存为… → 格式选网页归档，得到的是 .webarchive，不是同一种格式，AI 通常读不了。请改用 Chrome 或 Edge。

On a phone手机上Chrome and Edge on a phone cannot save this format. Copy the text or take screenshots instead.手机上的 Chrome 和 Edge 存不了这种格式。请改为复制文字或截图。

Works with适用Only AIs that accept file uploads (ChatGPT, Claude, Gemini). Free plans may refuse the file or read only part of it. Best when you have many questions at once.只有支持上传文件的 AI（ChatGPT、Claude、Gemini）。免费版可能拒收，或只读一部分。适合一次有很多题的时候。

PDFPDF
Computer only仅限电脑Upload needed需要上传文件

How做法On a computer, print (⌘P or Ctrl+P), set the destination to Save as PDF, and attach the file.在电脑上打印（⌘P 或 Ctrl+P），目标选另存为 PDF，再把文件作为附件发给 AI。

On a phone手机上Skip it. Copy the text or take screenshots.别用这个，复制文字或截图。

Works with适用Same limits as .mhtml: it needs file upload, and free plans may cut a long file short.限制和 .mhtml 一样：需要能上传文件，免费版可能把长文件截短。

Before you send anything发送之前

  • Use the page with the correct answers. Without it the AI has to guess, and marks those questions "source":"answer unverified".用带正确答案的页面。否则 AI 只能猜，并把这些题标成 "source":"answer unverified"（答案未核实）。
  • Figures do not come through. An AI cannot put a picture into the JSON, and the catalog has no picture upload. Give it a screenshot so it can see the figure, and let it describe the figure in the question text — or skip that question. Adding a real picture means editing the file by hand: the image field takes a public link or a data:image/… string (Question fields). A link that needs a Canvas login will not show.图片带不过去。AI 没法把图片放进 JSON，目录页也不能上传图片。给它截图让它看见图，并让它把图用文字写进题干——或者跳过这道题。想放真正的图，只能手动改文件：image 字段接受公开链接或 data:image/… 字符串（见题目字段）。要登录 Canvas 才能看的链接是显示不出来的。
  • Mind your privacy. Quiz pages can show your name, scores and course. Copy or crop just the questions if you would rather not share the rest. The prompt tells the AI to ignore them, but it still receives whatever you send.注意隐私。测验页面可能带着你的姓名、分数和课程名。不想分享的话，只复制或截取题目部分。提示词会让 AI 忽略这些，但你发出去的内容它都会收到。

Write it with an AI用 AI 来写

Free ChatGPT or Gemini is enough. Paste the prompt, then add your material after the last line or attach it.免费版 ChatGPT 或 Gemini 就够了。先粘贴提示词，再把材料接在最后一行后面，或作为附件发出。

Prompt提示词· plain text· 纯文本 
Turn the material at the bottom (pasted text, or attached screenshots / PDF / .mhtml file) into a question-bank JSON array. Reply with JSON only — do not restate these instructions.

BATCHES (important — free ChatGPT/Gemini cut long replies off): give me AT MOST 15 questions per reply. Stop after 15, and end that reply with the single line: MORE AVAILABLE. When I type "more", continue with the NEXT questions in the same format, never repeating ones you already gave. If everything fits in 15, end with: DONE.

FORMAT — a bare JSON array, one object per question:
[
  {"id":"q1","question":"Which fabric is approved for aircraft covering?","choices":["Polyester","Cotton bedsheet","Nylon tarp"],"answer":0},
  {"id":"q2","question":"Select ALL tools required. (multiple answers)","choices":["Punch tester","Hammer","Maule tester"],"answers":[0,2]},
  {"id":"q3","type":"fill","question":"A hole smaller than ____ inches may be patched.","blanks":[["8","eight"]]}
]

RULES
1. "id": unique short string. "question": the stem as plain text.
2. One correct answer: "choices" (2 or more strings) + "answer" = the 0-based index (first choice = 0). A plain integer, not [2], not the answer text, not 1-based.
3. Several correct answers: use the plural key "answers" = array of indexes, e.g. [0,2].
4. Fill in the blank: "type":"fill", put ____ in the question where the blank goes, and "blanks" = one array per blank listing every accepted answer, e.g. [["8","eight"]].
5. Optional: "explanation" (one short sentence of why), "source" (where it came from).
6. Include every question in this batch. Use the answer the material marks correct; if none is marked, pick the best-supported one and add "source":"answer unverified".
7. Straight ASCII quotes. No trailing commas. Do not wrap the array in an object.
8. Attached file or screenshots: read EVERY question in it, use the correct answer the page marks, and ignore interface text (scores, names, dates, buttons).
9. Never invent an image or an image URL. If a question needs a figure, describe the figure in words inside "question".
10. If an attachment is unreadable or looks cut off, do not guess: put ONE plain line saying so BEFORE the JSON (no square brackets in it), then give the JSON for what you could read, and still end with MORE AVAILABLE or DONE.

You may put the JSON in a code block and write a sentence before it — the importer strips that. Just never split one batch across two replies.

=== MATERIAL ===

Long quiz? It comes in batches of 15题很多？会分批，每批 15 题

  • The AI stops every 15 questions and ends with MORE AVAILABLE. Reply “more” for the next batch, until a reply ends with DONE.AI 每 15 题停一次，并以 MORE AVAILABLE 结尾。回一句 “more” 要下一批，直到某次回复以 DONE 结尾。
  • Paste every batch on the catalog with the same bank name and Add to the same bank on (it is on by default). Questions already in the bank are skipped.每一批都粘贴到目录页，题库名称保持一致，并保持并入同名题库开着（默认就是开的）。已经在题库里的题会被跳过。
  • A different quiz? Give it a new bank name. The default name (“My bank”) is the same every time, so a second quiz pasted under it is merged into the first. With the switch off, a paste under an existing name replaces that bank.换了另一份题？请起一个新的题库名称。默认名称（“我的题库”）每次都一样，用它粘贴第二份题会被并进第一份。把开关关掉的话，用已有的名称粘贴会替换掉那个题库。
Why 15 at a time? Free accounts cut long replies off. If one still gets cut off, the importer keeps every complete question and tells you to ask the AI for the rest.为什么一次 15 题？免费账号会把长回复截断。万一还是被截断，导入器会保留所有已完整的题，并提示你去向 AI 要剩下的。

Question fields题目字段

A bank is a JSON array of question objects, graded as single choice, multiple answer or fill in the blank. Using an AI? You can skip to If an import fails. Writing by hand? Start here.题库是一个由题目对象组成的 JSON 数组，可判分的题型有单选、多选、填空三种。用 AI 写的话，可以直接跳到导入失败了怎么办；手写的话，从这里看起。

Every question每一题

idRequired必填
Unique within the file, e.g. "ch3-12". Wrong answers and stars are saved against it. A missing one becomes auto-1, auto-2…, but auto ids shift if you reorder the file.文件内唯一，如 "ch3-12"。错题和收藏都记在它名下。缺了会补成 auto-1、auto-2……但调整文件顺序后自动 id 会变。
questionRequired必填
The stem, as plain text. \n makes a line break. May be empty when the question has an image.题干，纯文本。\n 表示换行。有 image 时可以留空。

Choice questions选择题

choicesRequired必填
At least 2 strings.至少 2 个字符串。
answerSingle choice单选
The 0-based index of the correct choice. The first choice is 0.正确选项的下标，从 0 开始。第一个选项是 0。
answersMultiple answer多选
Array of 0-based indexes, e.g. [0,2]. The player switches to checkboxes; every one must match.下标数组，如 [0,2]。播放器自动变成复选框，必须全对。

Fill in the blank填空题

typeFill in填空
Set to "fill" — or just provide blanks.写成 "fill"——或者只提供 blanks 也行。
blanksFill in填空
One array per blank, listing every accepted answer. [["8","eight"]] is one blank with two spellings; [["a"],["b"]] is two blanks.每个空一个数组，列出全部可接受的答案。[["8","eight"]] 是一个空、两种写法；[["a"],["b"]] 是两个空。
question_htmlOptional可选
A stem with <input data-blank="1"> where each blank goes (1-based). Leave it out and the boxes appear under the stem.题干里用 <input data-blank="1"> 标出每个空的位置（从 1 数起）。不写则输入框出现在题干下面。
answer_setsOptional可选
Whole-row combinations. Any one set that matches every blank counts as correct.整行组合。任意一组与所有空都匹配即算对。

Optional extras可选字段

image
An image URL or a base64 data:image/… string, or an array of them. Shown above the choices.图片 URL 或 base64 data:image/… 字符串，也可以是它们的数组。显示在选项上方。
explanation
Why the answer is right, as plain text (HTML is shown literally). Hidden until the learner answers: Show explanation after a right answer, Show answer after a wrong one. It never gives the answer away early.答案为什么对，纯文本（写 HTML 会原样显示）。作答前一直隐藏：答对后点Show explanation，答错后点Show answer。绝不会提前泄题。
source
Where the question came from, shown small under the card. May be an array — a merged question keeps every origin.题目出处，小字显示在卡片下方。可以是数组——合并后的题会保留每个来源。
section
A group name, such as a reading passage title. Questions keep their order and are never shuffled. IELTS page分组名，比如阅读文章的标题。带 section 的题保持原顺序，不会被打乱。雅思专页
passage
The reading text for a section, shown once above its first question. Read from the first question of each section only.某个 section 的阅读文章，显示在该组第一题上方，只出现一次。只读取每组第一题上的 passage。
banks
Filter groups this question belongs to. Defaults to the part of id before the first -.这道题所属的筛选分组。默认取 id 中第一个 - 之前的部分。

Other fields are ignored, so extra bookkeeping is harmless. type:"essay" is shown but not graded, and the importer drops it.其他字段会被忽略，所以多写几个备注字段无妨。type:"essay"（问答题）能显示但不判分，而且导入时会被剔除。

How answers are graded怎么判分

  • Multiple-answer questions need the exact set. There is no partial credit.多选题必须选对完整的一组，没有部分分。
  • Fill-in answers ignore case, extra spaces and spacing — check list = checklist. Curly quotes, dashes and a trailing full stop are evened out first, so 8. = 8.填空忽略大小写、多余空格和空格有无——check list = checklist。比较前会先统一弯引号、破折号并去掉句尾标点，所以 8. = 8。
  • Numbers compare as numbers, but only when the expected answer is numeric: 1,000 = 1000, 8 RPM = 8, 8% = 8. Units are not converted — 1 ft ≠ 12 in.数字按数值比较，但仅当期望答案本身是数字时：1,000 = 1000、8 RPM = 8、8% = 8。不做单位换算——1 ft ≠ 12 in。
  • blanks checks each blank on its own; answer_sets checks whole rows. Every blank must be filled before a question is graded.blanks 逐个空判断；answer_sets 按整行判断。所有空都填了才会判分。

Fixed on import导入时自动修复

Common slips, mostly from AI replies, are repaired instead of rejected. A clean file is still safer.常见的小毛病（多半来自 AI 的回复）会被修好而不是拒收。不过文件干净总是更稳。

  • Chat text around the JSON, code fences, and an outer {"questions":[…]} wrapper are removed.JSON 前后的聊天文字、代码围栏，以及外层的 {"questions":[…]} 包裹，都会被去掉。
  • Curly quotes and trailing commas are straightened out. A reply cut off halfway keeps every complete question.弯引号和多余的尾逗号会被修正。回复被截断在半途时，已完整的题都会保留。
  • About the “looked cut off” warning. It appears whenever the importer had to fix curly quotes or trailing commas, or recover questions one by one — even if only a comma was wrong. Check the question count in the message: if it matches your quiz, ignore the warning; if not, ask the AI to continue and paste the rest with Add to the same bank on.关于“看起来被截断”的警告。只要导入器修过弯引号或尾逗号，或是逐条抢救过题目，就会出现——哪怕只是错了一个逗号。看一下提示里的题数：和你的题目数一致，就不用理会；不一致，就让 AI 接着写，并在并入同名题库开着的情况下粘贴剩下的。
  • A missing id becomes auto-1, auto-2… Give real ids anyway — history is saved against them, and auto ids shift if the file is reordered.缺 id 会补成 auto-1、auto-2……还是请自己写真正的 id——历史记录靠它保存，调整文件顺序后自动 id 会变。
  • A numeric id becomes a string; an index written as "2" becomes a number.数字 id 会变成字符串；写成 "2" 的下标会变成数字。
  • answer:[2] becomes answer:2, and answer:[0,2] becomes answers:[0,2].answer:[2] 会变成 answer:2，answer:[0,2] 会变成 answers:[0,2]。

If an import fails导入失败了怎么办

“Not valid JSON”“Not valid JSON”（不是合法 JSON）
Remove comments and trailing commas, and use straight " quotes.去掉注释和多余的尾逗号，并使用直引号 "。
“No valid questions found”“No valid questions found”（没有有效题目）
The top level must be a bare array […], not an object.最外层必须是裸数组 […]，不能是对象。
Every question skipped所有题都被跳过
Usually a missing id or a bad answer. Make answer a 0-based whole number in range — not the text, not 1-based.通常是缺 id 或 answer 不对。answer 要写成范围内、从 0 开始的整数——不是文字，也不是从 1 开始。
The AI can’t open or only half-read the fileAI 打不开文件，或只读了一半
Free plans often refuse or truncate uploads. Paste the copied text instead, or send screenshots a few at a time. Safari’s .webarchive will not work.免费版常常拒收或截断上传的文件。改为粘贴复制的文字，或几张几张地发截图。Safari 的 .webarchive 不行。
Questions say “answer unverified”题目的 source 写着 “answer unverified”
The material did not show the correct answers, so the AI guessed. Redo it from the results or review page that marks them.材料里没有显示正确答案，AI 是猜的。请从标出正确答案的结果或回顾页面重来。
One question skipped只有一题被跳过
A choice question needs 2+ choices and a valid answer; a fill-in needs blanks with at least one accepted answer.选择题需要 2 个以上 choices 和有效的 answer；填空题需要 blanks，且每个空至少一个可接受答案。
